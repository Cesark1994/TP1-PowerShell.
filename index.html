Trabajo Práctico N.º 1 — PowerShell

Docente: Lic. Carlos Pacheco

Objetivo

Consultar desde PowerShell la versión del intérprete, las políticas de ejecución, la edición de Windows y la información general del equipo mediante systeminfo.

Comandos utilizados

  • $PSVersionTable
  • Get-ExecutionPolicy y Get-ExecutionPolicy -List
  • Get-CimInstance Win32_OperatingSystem
  • systeminfo
Descargar script PowerShell (.ps1)

La página describe el trabajo. Para ver los resultados reales, se debe ejecutar el script en una computadora con Windows.
